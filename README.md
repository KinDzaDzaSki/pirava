# ПИРАВА · катастарска мапа

Интерактивна мапа на **КО Пирава** (катастарско одделение Валандово) со сите 2.210 парцели, површини, начин на користење, имотни листови и сопственици — плус **ортофото** подлога од АКН.

Чист статичен сајт: HTML + CSS + JS, без билд, без сервер, без tracking. Работи и офлајн (освен ортофотото).

## Што има

- **Табови / множества**
  - Сите парцели во КО (2.210)
  - Приватни 800–1.500 m² (345)
  - 5 месности: СЕЛО · Е.КАРДЕЉ · М.ТИТО · Г.ДЕЛЧЕВ · ЧИФЛИК (188)
  - Градежно неизградено земјиште ★ (7)
- **Ортофото** подлога (АКН ортофото 2023, WMTS) — копче „Ортофото“ во хедерот
- **Филтри**: 8 категории користење, 9 месности, пребарување по парцела или сопственик
- **Клик на парцела** (карта или листа) → детали: површина, користење, имотен лист, сопственик, статус, координати, Google Maps
- **Пан/зум**: тркалце, влечење, пино-зум на телефон, копчиња +/−/⤢
- **Мини-карта**, размерник, северна стрелка, легенда
- **CSV извоз** на тековниот филтер
- Мобилен layout: листата е bottom-sheet, деталите се појавуваат долу

## Извори на податоци

| Што | Од каде |
|---|---|
| Геометрија и атрибути на парцели | АКН e-услуги, WFS слој `KIS:PARCELI` (`/api/v2/geo/proxy/wfs_geoserver_vector`) |
| Имотни листови и сопственици | `/api/v2/propertyCertificates/*` (920 имотни листа) |
| Ортофото | `/geo/proxy/ortofoto23/wmts`, слој `APP_DATA:ORTOFOTO_2023`, EPSG:6316, матрица `APP_GRID_ORTOFOTO_2023` |

Состојба на податоците: **22.10.2026**. Сите податоци се јавни катастарски податоци на АКН.

Површината на парцела е земена од главниот дел на парцелата (имоотен лист), а не од поединечни делови (згради), за да не се дуплираат површини.

## Структура

```
index.html    – markup
app.css       – стилови (десктоп + мобилен)
app.js        – сета логика: филтри, зум, ортофото тајли, извоз
data.js       – податоци (2.210 парцели, геометрија + атрибути)
```

## Локално пуштање

```bash
python -m http.server 8000
# → http://localhost:8000
```

(може и директно со отворање на `index.html`, но локален сервер е постабилен)

## Ортофото — како работи

Тајлите се влечат директно од АКН WMTS проксито, во националниот координатен систем EPSG:6316, со слободна мрежа `APP_GRID_ORTOFOTO_2023` (резолуции 560 → 0,14 m/px). Нивото се избира автоматски според зумот, а бројот на тајли е ограничен на 64 по приказ. Ако АКН го смени сервисот, ортофотото едноставно повеќе нема да се вчитува — остатокот од мапата работи.
